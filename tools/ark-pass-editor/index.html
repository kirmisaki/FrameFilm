ARKNIGHTS个人档案 — 01

个人通行证

以罗德岛终端档案为视觉参考，本地编辑个人资料并生成设备主体图。头像和资料仅在此浏览器页面处理。

01 / 档案资料

编辑资料

两种模板分别保留本地草稿及头像构图；设备仅保存一份活动卡面。学生证使用本地 PSD 导出的静态底图，头像和文字资料可编辑。

使用 PSD 原配色，仅替换底图，保留头像和档案资料。

I006 只改变位图出图方式，不修改头像或编辑资料。发送时若设备不支持 I006，会使用设备支持的全屏 FFUI。

头像数据128×160，学生证按4:5放大显示；本地保留源图，可拖动、缩放、旋转和调整Film抖动，取消保留旧头像。

设备JSON仅含最终128×160头像；重新读取后可编辑该图像，完整构图请重新导入原图。源图和调整参数仅保存在本地草稿。

12 位：实装日期 YYYYMMDD + 生日 MMDD（生日允许 02-29）。保留前导零，不自动生成。

02 / 本地文件

保存与导入

干员档案导出 v1 JSON；学生证导出 v2 JSON。旧网页及 Flutter 客户端不支持学生证编辑，仍可能直接上传旧草稿覆盖设备卡面；换模板前请在新版网页读取并导出备份。

03 / 设备连接

发送到 Ark

通过浏览器手动选择 FRAMEFILMARK。发送到固定路径 app/pass/profile.bin 与 app/pass/profile.json；读取成功后切换并替换对应模板草稿，另一模板草稿保留。

使用 ForFilm 已连接的 Ark。依次发送 profile.bin 和 profile.json；读取成功后才切换并替换对应模板草稿，另一模板草稿保留。

未连接。浏览器需支持 Web Bluetooth，并在 localhost 或 HTTPS 打开。

440 × 608 / 设备色彩

设备主体预览

学生证按 720 × 480 横版全屏编辑和下载 PNG。I006 BIN 使用面板原生 ABC9 排布；兼容 FFUI 则为 480 × 720。请将 Ark 逆时针横拿阅读。全屏不显示状态栏和底部提示，按键操作不变。预览是模型色彩，实际效果以屏幕为准。

预览即导出像素。灰度使用黑白网点；彩色使用六色资料，新版固件通过 ColorFast 彩色快刷显示，页面时间静态。快刷颜色以实机为准。设备状态栏与脚注由固件绘制，不包含在文件内。
