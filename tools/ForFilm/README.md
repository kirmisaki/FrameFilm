# ForFilm · Ark 网页操作

沿用 ForFilm 的连接、Frame、Film、动画和设置布局，新增“通行证”入口。Ark 连接后的品牌统一为 ARKNIGHTS / RHODES ISLAND，保持原有网页结构；其他机型保留原页面。

Ark 专属主题只在 Ark 蓝牙连接及通知初始化成功后启用。每次新连接显示浅灰登录入口：线框描绘与徽标显现、标题淡入；点击“开始唤醒”播放终端几何动效，再淡出至深色 PRTS 工作台。这里的“唤醒”仅进入网页，不发送设备唤醒指令；状态文字只描述界面过渡，不冒充蓝牙或文件上传进度。可跳过或按 Esc，系统减少动态效果时直接切换。

同一连接内的状态刷新和主题开关不重复播放；连接状态下可在设置中重看。断开会立即取消全部登录动画与延迟回调，恢复原 ForFilm 外观，重连后开始新的引导会话。Logo 保留 SVG 矢量形状，登录页使用纯黑、深色页头使用纯白，不叠加透明度或混色。

工作台使用炭灰直角面板、黑白对比标题、细边框和冷蓝活动状态。连接页、制作工具、设置及嵌入的通行证编辑器共享外观规范；设备预览画布仍保持实际黑白像素。主题开关可恢复原 ForFilm 外观，切换不丢弃通行证草稿。

主题入口脚本使用 `prts-3`，主题、加载页和编辑器样式使用 `prts-4` 资源标识，避免浏览器继续使用旧资源。此标识只用于网页资源更新，与固件版本无关。

加载页适配手机安全区和矮横屏，空间不足时可滚动；背景与内容同步淡出。主界面与通行证编辑器统一按钮反馈和键盘焦点提示，手机端文本输入使用 16px 字号。

Frame、Film、动画和设置页共用同一套表单、滑杆、状态标签与消息提示；展开的网络面板和键盘弹窗也跟随主题。动画的播放、放大、应用到所有帧等选中状态使用冷蓝底深色文字。照片预览、绘图画布及实际调色板保持内容原色。

正常入口为 `http://127.0.0.1:8768/ForFilm/`。旧 `?theme=ark` 参数不再启用主题；未连接时始终保持原网页。

## 本地使用

从仓库根目录启动静态服务（服务根必须是 `tools`，以提供通行证编辑器和共享资源）：

```powershell
python -m http.server 8768 --bind 127.0.0.1 --directory tools
```

在支持 Web Bluetooth 的浏览器打开 `http://127.0.0.1:8768/ForFilm/`。首次点击“蓝牙扫描”并选择 Ark；同一页面中断开后可“重连上次”。蓝牙选择窗口须由用户操作。USB 连接入口用于 Dock，Ark 的 CH343 用于供电和固件调试。

## 页面与操作

```text
设备连接 → 扫描 / 已授权设备重连 / 当前任务取消
Frame / Film / 动画 → 保留现有制作工具
Film → Ark 蓝牙上传进度 / 取消 / 同文件从头重试
通行证 → 编辑与预览 / JSON 导入导出 / 设备读取 / 双文件发送
设置 → Ark 系统页入口 / 遥控 / 改名 / WiFi 直传状态与取消 / OTA
```

- Ark 仍按 `FRAMEFILMARK` 前缀识别，兼容默认唯一名称与中文后缀。屏幕参数不能把 Ark 改判成 Pro。改名后重启广播才生效，自定义名称不做全局查重。
- 通行证编辑器在同源页面内复用 `ArkDevice` 的同一条 BLE 连接，不再单独配对。资料保存在 SD 卡，网页保留本地草稿。读取前会确认，完整校验通过后才替换草稿；失败或取消不覆盖编辑内容。发送顺序为 `profile.bin`、`profile.json`，发送后通过 `0x53` 回读 `profile.json` 比对，部分完成会明确提示；不是双文件原子事务。
- Ark 普通图片上传可以取消，取消后断开以触发设备撤销未完成文件。重连后“从头重试”重新发送整份文件，不做断点续传。发送过程中锁定冲突操作；每 32 包及文件结束后等待设备处理查询，避免连续发送挤满队列。固件没有保存 ACK，网页报告“已发送，待设备确认保存”，不将 GATT 成功等同于 SD 保存成功。
- 语言、开机画面和启动应用尚无 BLE 读写接口。网页提供“打开设备系统设置”和遥控，在设备屏幕上修改。Ark 不再显示或发送已废弃的 `0x20/0x21` 照片模式控制。
- WiFi 直传状态经 `0x51` 查询，取消经 `0x52` 请求并等到终态；恢复网络中的 100% 不代表完成。浏览器不创建手机 WiFi Direct 网络，也不提供手机侧临时 HTTP 文件服务；网页图片发送仍为 BLE。
- OTA 检查 Ark 应用镜像、ESP32-S3 标识与 1900 KiB 分区限制，擦除后等待服务响应再发正文。3.2.5 整分区擦除已有超出 BLE 超时的实机记录，页面遇到断连会停止并提示人工恢复，不盲目重发/自动续传；结束阶段也只报告待重启核验。本轮网页适配没有修改固件 OTA 协议或擦除策略。

## 最小验证

```powershell
node --test tools/ForFilm/tests/ark-device.test.cjs
# 需先启动上述静态服务，安装/提供 Playwright，并可启动 Edge
node tools/ForFilm/tests/ark-browser.test.cjs
node tools/ForFilm/tests/ark-upload-ui.test.cjs
# 仅检查主题连接/断开、开关、编辑器同步和移动端布局
node tools/ForFilm/tests/ark-theme.test.cjs
# 仅检查连接门槛、登录动画播放/中断、重连与减少动态效果
node tools/ForFilm/tests/ark-intro.test.cjs
# 仅检查布局精修、淡出、按钮对比与编辑器焦点
node tools/ForFilm/tests/ark-polish.test.cjs
# 仅检查 Frame 子页面、Film、动画与设置的主题覆盖
node tools/ForFilm/tests/ark-pages.test.cjs
# 异步图片完成与 busy 锁、直传状态的断连/重连归属
node tools/ForFilm/tests/ark-state.test.cjs
```

浏览器用模拟 BLE 验证共享连接、读失败保留草稿、取消/重连/发送、直传状态与取消、OTA 文件拦截及移动端布局，不写入真实设备。真实蓝牙和 SD 保存行为需要单独验收。
