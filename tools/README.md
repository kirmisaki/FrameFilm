# 工具目录

本目录包含帧影（FrameFilm）项目开发、调试和生产相关的辅助工具和脚本。

## 目录结构

- `flash/` - 固件烧录工具和脚本
- `debug/` - 调试工具和日志分析脚本
- `production/` - 生产测试工具
- `utils/` - 通用工具脚本
- `photo-utils/` - 照片处理和滤镜开发工具

## 工具说明

### 固件烧录工具

用于将编译好的固件烧录到 ESP32 芯片中，支持批量烧录和 OTA 更新。

### 调试工具

- 串口日志查看
- 性能分析
- 蓝牙连接调试
- 功耗测试

### 生产测试工具

用于工厂生产阶段的硬件功能测试和校准：
- 屏幕显示测试
- 蓝牙连接测试
- 电池充电测试
- 功能完整性检查

### 照片处理工具

用于开发和调试胶片滤镜效果：
- 滤镜效果预览
- 色彩空间转换
- 照片压缩工具
- 效果批量测试

## 使用说明

各子目录包含具体工具的使用说明，请参考对应目录的 README。
