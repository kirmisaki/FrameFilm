卡包 · NFC WALLET

480×720 竖屏、纯 1-bit 的卡包 app 原型。包含封面卡片板、模拟模式、读卡复制、空状态、NFC 未就绪、 返回键/双击返回两种按键变体，以及 BLE 远程建卡、封面、重命名/删除后的界面状态。

TARGET   E6 3.70" 720×480 → 480×720 (logical portrait)
DEPTH    1 bpp  ·  REFRESH  每按键一整帧（约 410 ms） ·  INPUT  UP / DOWN / ENTER / BACK
BACK     n16r8 = GPIO18 返回键；n4r2 = 双击确认键

03 状态与数据

状态触发界面
EMU 有卡进入卡包 / 选中卡封面 + 信息条 + 列表 + “模拟中 · 等待读卡器”
EMU 无封面卡未上传封面几何默认封面 + 信息条；不显示 UID
EMU 空卡包无 SD / 清空钱包图标 + “尚未添加卡片” + 双击读卡
EMU 硬件未就绪chip_info 失败状态行 “NFC 硬件未就绪”，双击不进入读卡
COPY scanning双击进入读卡页“正在读卡…” + 分段指示 + 单击取消
COPY done读到 NTAG / M1结果四行 + 底部「复制卡」按钮
COPY fail超时 / 不支持失败原因 + 单击重试
MENUBACK主菜单占位；ENTER 重新进入卡包
SLEEP长按 ENTER休眠卡；ENTER 模拟唤醒
数据模型：最多 16 张卡；每条包含 id / kind / uid_len / sak / atqa / uid / name / mem_len / has_cover / cover_len。 本原型只绘制元数据与封面缩略图，NTAG 内存镜像不进入 UI 快照；封面区不显示 UID。
