TAMAGO · 掌上宠物

把万代拓麻歌子的经典养育闭环搬到 480×720 的 1-bit 电子纸上：蛋、幼年、进化、饥饿/快乐/教养、 喂食、清洁、吃药、小游戏、昼夜作息、便便、生病、死亡与代数。原型用三键操作，并演示“离线时间补算” 与睡前存档，验证这套玩法在 Ark 的刷新与功耗约束下是否成立。

TARGET   E6 3.70" 720×480 → 480×720 (logical portrait)
DEPTH    1 bpp  ·  REFRESH  MonoFast 差分 197–410 ms / 首帧约 940 ms
INPUT    UP / DOWN / ENTER  ·  双击 ENTER 回主菜单  ·  长按 ENTER 全局休眠
SCOPE    经典 P1/P2 养育闭环；不含音效、联机与彩色动画

03 状态与数值

项目原型规则设计意图
成长阶段蛋 0–2h → 幼年 2–8h → 少年 8–20h → 青年 20–40h → 成年 40h+按“存活游戏小时”推进，不依赖真实日期
饥饿 / 快乐各 0–4 心；清醒时每 2h / 3h 掉 1 心低值时触发 CALL；归零后进入死亡倒计时
教养0–5 格；每 8h 出现一次管教时机，2h 内不处理记一次照顾失误把“呼救”从随机事件改成可演示的计时器
便便 / 生病每 4h 便便 +1（上限 3）；有便便时每 5h 判定生病清洁与吃药构成负反馈闭环
睡眠21:00–08:00 自动睡；睡眠中饥饿/快乐暂停，但开灯会掉快乐并增加生病率对应电子纸“静止即省电”的形态
死亡饥饿与快乐同时归零 6h，或生病未治 12h保留拓麻歌子的“不可逆”压力
时间补算进入 app / 定时唤醒时按时间差一次性推进；原型用“离线 6h”按钮演示固件 deep sleep 后靠 RTC 时间补算，不要求进程常驻
喂食正餐 +1 饥饿 +1 体重；零食 +1 快乐 +1 体重体重随喂食上升，游戏/时间缓慢下降
小游戏3 回合猜高低；≥2 回合胜利 → +1 快乐 −1 体重三键即可完成，不需要额外输入设备
按键↑↓ 选图标 / 选项；短按确认键执行；双击返回；长按休眠完全复用 Ark 的全局按键语义
原型把时间加速到 300×，便于在几十秒内看到掉心、便便、生病与进化。固件里这些计时使用 真实时间，并在每次唤醒时按 time() 差值补算，因此设备睡多久都不会“饿死”在睡梦里。

原型元素固件落点

双击回菜单 / 长按休眠框架全局语义，app 不需要额外实现；长按走 app_manager_sleep_from_app()
夜间休眠 / 定时唤醒hal_pwr_set_timer_wakeup()（分钟级）+ time() 跨 deep sleep 保持
刷新节奏hal_epd_display_mono() MonoFast 差分；UI I1 → mono 转置
菜单入口app_manager.c 的 m_menu_entries[] 与 app_menu.c 的 MENU_ITEMS[] 同序追加
无蜂鸣器用 WS2812 闪灯 + 屏幕 CALL 图标替代音效，不伪造声音
完整取舍见对话中的评估：经典 P1/P2 的养育闭环可覆盖；联机/结婚、商店、触屏、彩色逐帧动画 依赖 Ark 没有的硬件或波形能力，不在本版范围。
