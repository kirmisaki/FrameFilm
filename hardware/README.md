# 硬件目录

本目录包含帧影（FrameFilm）电子胶片冰箱贴的硬件设计文件。

## 目录结构

- `pcb/` - PCB 电路板设计文件
- `models/` - 外壳 3D 模型文件

## 硬件规格

### 核心组件

- **主控芯片**：ESP32-S3（双核处理器，Wi-Fi + 蓝牙）
- **显示屏**：彩色电子纸（E-Ink）3.6"
- **存储**：TF 卡
- **电池**：锂电池（可充电）
- **通信**：蓝牙 BLE 4.2

### 物理规格

- **尺寸**：约 92 x 60 x 7 mm
- **安装方式**：背部磁吸

## 设计说明

本目录包含完整的硬件设计资料，包括：
- 电路原理图和 PCB 布局
- 外壳 3D 模型（用于 3D 打印）
- 物料清单（BOM）
- 生产和加工文件
