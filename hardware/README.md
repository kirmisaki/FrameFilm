# 硬件目录

本目录包含帧影（FrameFilm）电子胶片冰箱贴的硬件设计文件。

## 目录结构

- `pcb/` - PCB 电路板设计文件
- `schematics/` - 电路原理图
- `3dmodels/` - 外壳 3D 模型文件
- `bom/` - 物料清单
- `datasheets/` - 芯片数据手册
- `gerber/` - PCB 加工文件

## 硬件规格

### 核心组件

- **主控芯片**：ESP32-D0WDQ6（双核处理器，Wi-Fi + 蓝牙）
- **显示屏**：彩色电子纸（E-Ink）3.7"
- **存储**：SPI Flash
- **电池**：锂电池（可充电）
- **通信**：蓝牙 BLE 4.2

### 物理规格

- **尺寸**：约 120 x 80 x 15 mm
- **重量**：约 150g（含电池）
- **安装方式**：背部磁吸

## 设计说明

本目录包含完整的硬件设计资料，包括：
- 电路原理图和 PCB 布局
- 外壳 3D 模型（用于 3D 打印）
- 物料清单（BOM）
- 生产和加工文件

## 设计软件

- 原理图和 PCB：KiCad / Altium Designer
- 3D 模型：SolidWorks / Fusion 360
